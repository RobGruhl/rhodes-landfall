# Jamie research: fact-check summary (round one, 8 September 2026)

Each research/jamie-*.md ends with a "## Fact-check" section listing every claim checked. This file collects only the claims that were not simply confirmed, so a scriptwriter can see at a glance what was corrected, removed, or left unverifiable. The body text of each file was edited to match.
